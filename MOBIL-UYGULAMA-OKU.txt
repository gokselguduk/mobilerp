SIMTEKS TEKSTİL ERP — MOBİL UYGULAMA
====================================

Amaç: Mobil ERP'yi telefonda kurulu UYGULAMA olarak açmak.
Android ve iOS AYRI platformlardır (ayrı klasör, ayrı derleme).

Ortak içerik:  mobile-app\public\   (MOBIL-WWW-OLUSTUR.bat)
Android:       mobile-app\android\
iOS:           mobile-app\ios\

Veri Supabase üzerinden gelir (internet gerekir).


1) ANDROID (Windows PC)
-----------------------
Betik:  MOBIL-ANDROID-HAZIRLA.bat
        (eski ad: MOBIL-APK-HAZIRLA.bat → aynı iş)

Gereksinim: Android Studio + Android SDK

Adımlar:
  1. MOBIL-ANDROID-HAZIRLA.bat
  2. Android Studio → mobile-app\android
  3. Build → Build APK(s)
  4. APK'yı telefona kurun

APK yolu (örnek):
  mobile-app\android\app\build\outputs\apk\debug\app-debug.apk


2) iOS (ayrı — Mac gerekir)
---------------------------
Betik (Windows'ta iskelet/güncelleme):  MOBIL-IOS-HAZIRLA.bat

IPA üretmek için: Mac + Xcode (+ CocoaPods)

Adımlar (Mac):
  1. mobile-app klasörünü Mac'e alın
  2. cd mobile-app
  3. npm install
  4. npx cap sync ios
  5. cd ios/App && pod install
  6. npx cap open ios
  7. Xcode → Run / Archive

Windows'ta iOS klasörü oluşur ama App Store / cihaz
derlemesi yalnızca Mac'te yapılır.


3) PWA (hızlı deneme — tarayıcı ana ekran)
------------------------------------------
  MOBIL-WWW-OLUSTUR.bat
  Telefonda sayfayı aç → Ana ekrana ekle


GÜNCELLEME
----------
Kod değişince önce:
  MOBIL-WWW-OLUSTUR.bat

Sonra platforma göre:
  Android → MOBIL-ANDROID-HAZIRLA.bat  (veya: npm run sync:android)
  iOS     → MOBIL-IOS-HAZIRLA.bat      (veya Mac'te: npm run sync:ios)

İkisini birden:  cd mobile-app && npm run sync:all


KLASÖRLER
---------
  mobile-app\public\     ortak web içeriği
  mobile-app\android\    SADECE Android
  mobile-app\ios\        SADECE iOS
  assets\mobil\icons\    uygulama ikonları


NOT
---
Masaüstü EXE ≠ mobil uygulama.
Android APK ≠ iOS IPA — ayrı kurulur, aynı Supabase verisini kullanır.
