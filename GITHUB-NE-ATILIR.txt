SIMTEKS TEKSTİL ERP — NE ATILIR, NE ATILMAZ?
============================================

Tek cümle:
  GitHub  →  GITHUB-AT.bat  →  github-at\  →  yükle
  Sunucu  →  SUNUCUYA-AT-MOBIL.bat  →  sunucuya-at-mobil\  →  yükle


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1) GITHUB'A — TEK KLASÖR
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

   Adım 1:  GITHUB-AT.bat   dosyasına çift tıklayın

   Adım 2:  Açılan klasör:
              github-at\

   Adım 3:  Bu klasörün İÇİNDEKİ HER ŞEYİ GitHub'a sürükleyin
              (klasörün kendisini değil — içindeki dosyaları seçin)

   Web hata verirse (100 dosya limiti):
     GitHub Desktop → Add local repository → github-at → Publish


   Pakette YOK (bilerek):
     erp-config.js           → Supabase şifreleri
     erp-update.config.js    → güncelleme anahtarı
     mobile-app/android|ios  → cap sync ile üretilir
     node_modules / dist     → npm ile gelir
     sunucuya-at*            → sunucu paketi
     releases/*.exe          → USB kurulum

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
2) SUNUCUYA — SADECE MOBİL
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

   Adım 1:  SUNUCUYA-AT-MOBIL.bat   çift tıklayın
   Adım 2:  sunucuya-at-mobil\  içindeki her şeyi hosting'e yükleyin
   Adım 3:  https://siteniz.com/mobil-erp.html

   erp-config.js → sunucuya ATIN. GitHub'a ASLA ATMAYIN.


   ── Masaüstü + mobil sunucu paketi ──
   SUNUCUYA-AT.bat → sunucuya-at\


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
3) FABRİKA PC — WINDOWS KURULUM (.exe)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

   Sonraki sürüm: GUNCELLEME-YAYINLA.bat
