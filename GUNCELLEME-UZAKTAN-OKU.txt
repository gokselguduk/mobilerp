Simteks Tekstil ERP — Güncelleme
================================

Tek yol: GUNCELLEME-YAYINLA.bat
(Yama / EXE ayrımı yok.)


ÇALIŞMIYORSA (eski ekran / checkForUpdates hatası)
-------------------------------------------------
Sebep: AppData'da eski yama takılı kalır:
  %APPDATA%\tekstil-erp\content\stok.html

Çözüm (bu PC):
  1) Uygulamayı kapat
  2) ACIL-GUNCELLE.bat  çift tıkla
     → eski yamayı siler + Setup kurulumunu açar
  3) Kurulumu bitir, uygulamayı aç


0) BİR KEZ — GELİŞTİRİCİ KURULUMU
---------------------------------
a) supabase/migrations/erp_desktop_updates_storage.sql
b) erp-update.config.sample.js → erp-update.config.js
   service_role anahtarını yaz


1) YENİ SÜRÜM YAYINLA
---------------------
a) GUNCELLEME-YAYINLA.bat
   (sürüm otomatik +1 artar: 1.0.14 → 1.0.15)
b) Fabrika PC: açılışta "Güncelleme yükle"
   (bozulursa orada da yeni Setup / ACIL-GUNCELLE)

   Not: Sürümü artırmadan yeniden yayınlamak için:
   set ERP_SKIP_VERSION_BUMP=1 && npm run publish


2) KOMUTLAR
-----------
GUNCELLEME-YAYINLA.bat  → yayın
ACIL-GUNCELLE.bat       → bu PC'yi düzelt (eski yama + kurulum)
npm run publish         → aynı yayın
